Уведомления в Telegram

О каждой новой заявке бот пришлёт сообщение: номер заявки, что и на какие даты. ФИО и телефон в Telegram не отправляются, их видно только здесь.

  1. В Telegram откройте @BotFather, отправьте /newbot, придумайте имя. BotFather пришлёт токен.
  2. Вставьте токен ниже и нажмите «Сохранить».
  3. Напишите вашему боту любое сообщение (или добавьте бота в рабочую группу и напишите там).
  4. Нажмите «Найти мой чат», выберите чат и нажмите «Отправить тест».

Номера и синхронизация с Авито

Чтобы не было двойных броней, свяжите календарь каждого номера с объявлением на Авито. На Авито: объявление → «Управлять календарём» → «Синхронизировать календарь с другого сайта».

  1. Скопируйте ссылку из поля «Ваш календарь на Авито» и вставьте её ниже в «Ссылка из Авито». Брони с Авито появятся в календаре сайта (обновление каждые 15 минут).
  2. Нажмите «Копировать» у «Ссылка для Авито» и вставьте её на Авито в поле для календаря с другого сайта. Тогда брони с сайта закроют даты на Авито.
